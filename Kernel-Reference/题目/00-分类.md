# LeetGPU 题单按写法分类

站点：[leetgpu.com/challenges](https://leetgpu.com/challenges)。  
下面按 **并行模板** 归类（不是按 Easy/Medium）。`Kernel-Reference` 提供参考实现；表中未标注「有」的题目作为扩展练习，尚未收录实现。

## 1. Element-wise（逐点 Map）

每个输出只看同位置输入，线程互不通信。带宽墙。grid-stride + 向量化。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| Vector Addition | Easy | **有** `01_element_wise/01_vector_add` |
| Matrix Addition | Easy | 换公式，和 vector add 同一核 |
| Color Inversion | Easy | **有** `01_element_wise/02_color_inversion` |
| RGB to Grayscale | Easy | **有** `01_element_wise/09_rgb_to_grayscale` |
| Matrix Copy | Easy | **有** `01_element_wise/05_matrix_copy` |
| ReLU | Easy | **有** `01_element_wise/03_relu` |
| Leaky ReLU | Easy | **有** `01_element_wise/04_leaky_relu` |
| Sigmoid | Easy | **有** `01_element_wise/10_sigmoid`（`σ(x)`） |
| SiLU | Easy | **有** `01_element_wise/06_silu`（`xσ(x)`） |
| SWiGLU（切半门控） | Easy | **有** `01_element_wise/07_swiglu` |
| Value clipping | Easy | **有** `01_element_wise/08_value_clipping` |
| SwiGLU MLP | Medium | 扩展练习：GEMM + SwiGLU |

## 2. Permute（下标重排）

不改数值公式，改「谁写到哪」。反转两边都能合并；转置必须 smem。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| Reverse Array | Easy | **有** `03_permute/01_reverse_array` |
| Matrix Transpose | Easy | **有** `03_permute/02_matrix_transpose` |
| Interleave arrays | Easy | **有** `03_permute/03_interleave_arrays` |

## 3. Reduce / Scan

多读一写，或前缀依赖。shuffle + smem 树 + 可选 atomic。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| Reduction | Medium | **有** `02_reduce/01_reduction`（`common.cuh`） |
| Dot Product | Medium | **有** `02_reduce/04_dot_product`（融合乘加，勿先写乘积） |
| Softmax | Medium | **有** `02_reduce/02_softmax`（online `(m,ℓ)`） |
| Prefix Sum | Medium | **有** `02_reduce/03_prefix_sum` |
| Histogramming | Medium | 多桶 atomic，新骨架 |
| Top K / Top-p | Medium | 部分排序 + reduce |
| MSE / CCE | Medium | map + reduce |

## 4. GEMM / 乘加

算术强度高，tile + smem。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| Matrix Multiplication | Easy | **有** `04_gemm/01_matrix_mul` |
| Sparse MatVec（稠密布局） | Medium | **有** `04_gemm/02_spmv`（按行 GEMV，非 CSR） |
| **GEMM（α/β，FP16）** | Medium | **有** `04_gemm/03_gemm` |
| Batched GEMM | Medium | 同一套 tile |
| Sparse / INT8 MatMul | Hard | 扩展练习：稀疏布局、量化与反量化 |

## 5. Stencil / 卷积

一个输出吃一段邻域。输入被邻居复用 → smem halo；小 kernel 可放常量内存。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| 1D Convolution | Easy | **有** `05_stencil/01_conv1d` |
| 2D Convolution | Medium | **有** `05_stencil/02_conv2d` |
| 3D Convolution | Medium | **有** `05_stencil/03_conv3d` |
| Gaussian Blur / Max Pool | Medium | 固定 K 的 stencil |
| 2D Jacobi | Medium | 迭代 stencil |
| Causal Depthwise Conv1d | Medium | 加因果边界 |

## 6. Attention / Transformer

行归约 + GEMM tile；FA 再加 online merge。

| 题目 | 难度 | 参考实现 / 扩展方向 |
|---|---|---|
| Softmax Attention | Medium | **有** `06_attention/01_naive` · `02_online` · `03_flash_v2`（**不是**必须 FA） |
| Grouped Query Attention | Medium | 扩展练习：`kv_head = q_head / g` |
| RoPE | Medium | 扩展练习：旋转位置编码 |
| RMSNorm / BatchNorm | Medium | 扩展练习：归约与归一化 |
| Linear / Decaying Causal Attn | Medium | 扩展练习：线性与因果注意力 |
| SwiGLU MLP / MoE Top-K | Medium | 扩展练习：门控前馈与专家路由 |
| Simple Inference | Medium | GEMM + 激活拼盘 |

## 阅读顺序（本目录）

```
01_element_wise (add → color → ReLU → Leaky → copy → SiLU → SWiGLU → clip → gray → sigmoid)
    → 02_reduce (reduction → softmax → prefix_sum → dot)
    → 03_permute (reverse → transpose → interleave)
    → 04_gemm (matrix_mul → spmv → gemm)
    → 05_stencil (conv1d → conv2d → conv3d)
    → 06_attention (`01_naive` → `02_online` → `03_flash_v2`)
    → 07_sort (top_k_selection)
```
目录数字即阅读顺序：先解决「通信」（shuffle/scan/online），再进「tile」（permute→GEMM→stencil），attention 合流后，再练习 Top-K 选择。
