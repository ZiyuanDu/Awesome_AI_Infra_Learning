# 1. 向量加法

**难度：** Easy

给定两个长度均为 $N$ 的 32 位浮点向量 $A$ 和 $B$，在 GPU 上对它们做逐元素加法，将结果写入向量 $C$：

$$
C[i] = A[i] + B[i], \qquad 0 \le i < N
$$

## 示例 1

**输入：**

```
A = [1.0, 2.0, 3.0, 4.0]
B = [5.0, 6.0, 7.0, 8.0]
N = 4
```

**输出：**

```
C = [6.0, 8.0, 10.0, 12.0]
```

## 示例 2

**输入：**

```
A = [1.5, 1.5, 1.5]
B = [2.3, 2.3, 2.3]
N = 3
```

**输出：**

```
C = [3.8, 3.8, 3.8]
```

## 约束

- $A$ 与 $B$ 长度相同
- $1 \le N \le 10^{8}$
- 计时规模：$N = 2.5 \times 10^{7}$
- 评测卡：NVIDIA 5090Dv2
