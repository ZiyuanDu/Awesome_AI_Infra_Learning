# 2D 卷积（Stencil）

**LeetGPU：** Medium · [2D Convolution](https://leetgpu.com/challenges/2d-convolution)  
**目录：** `stencil/02_conv2d`

valid 边界，单通道：

$$
\mathrm{out}[i,j]=\sum_{m,n}\mathrm{in}[i+m,j+n]\cdot\mathrm{ker}[m,n]
$$

`out_rows = in_rows - k_rows + 1`（cols 同理）。行优先一维数组。

## 接口

```cuda
void solve(const float* input, const float* kernel, float* output,
           int input_rows, int input_cols, int kernel_rows, int kernel_cols);
```

`1 ≤ rows,cols ≤ 3072`，`1 ≤ k ≤ 31`。计时 `3072×3072`、`ker 15×15`。

## 为什么归 stencil

一个输出吃一块邻域；和 1D 卷积同一模板，多一维下标。不是 GEMM 默写档（单通道 + 显式 im2col 太贵）。

## 面试写法

照抄 `01_conv1d`：`16×16` 输出 tile，smem 放输入 halo。再加两刀（默写成本低）：

1. **核进 `__constant__`**：整 block 广播读，省 smem 带宽给输入
2. **行距 `tileC+1`**：避免邻线程读同一行时 32-bank 冲突

计时 `15×15` 已是算力墙；这两刀通常还能再挤一截。再往上（每线程多输出 / implicit GEMM）白板性价比低。
