# 矩阵拷贝（Element-wise）

**LeetGPU：** Easy · [Matrix Copy](https://leetgpu.com/challenges/matrix-copy)  
**目录：** `element_wise/05_matrix_copy`

把行优先的 \(N\times N\) 矩阵 \(A\) 拷到 \(B\)：

$$
B[i,j]=A[i,j]
$$

存储是连续的，下标不变，等价于拷 `N*N` 个 float。例：`[[1,2],[3,4]]` 原样到 \(B\)。

## 接口

```cuda
void solve(const float* A, float* B, int N);
```

`1 ≤ N ≤ 4096`，计时 `N=4096`（64MB×2）。

## 为什么在 element-wise，不在 permute

| | 矩阵拷贝 | 转置 | 反转 |
|---|---|---|---|
| 下标 | `out[i]=in[i]` | `out[c,r]=in[r,c]` | `out[i]=in[N-1-i]` |
| smem | 不需要 | 必须 | 不需要 |
| 分类 | **逐点恒等 map** | permute | permute |

名字带 Matrix，容易误放进 permute / gemm。公式是恒等，和 ReLU 同一核，连 `fmaxf` 都没有。

## 面试写法

1. **摊平 + `float4` + `__ldg`**（本目录）：128-bit 合并，只读缓存。`N*N%4≠0` 走标量尾巴（`N=3`）。
2. 口播：`cudaMemcpy(B,A,n*4,D2D)` 是驱动里的 copy 引擎，往往打满带宽；要默写核就写 1。
3. **不要：** 二维 `(row,col)` 再配 smem——那是转置的套路，这里多一次搬、还可能写跨步。
