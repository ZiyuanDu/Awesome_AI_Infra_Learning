# LeetGPU 题单按写法分类

站点：[leetgpu.com/challenges](https://leetgpu.com/challenges)。  
下面按 **并行模板** 归类（不是按 Easy/Medium）。`018` 只写默写档；带「019」的已在 `019-面试算子速通`。

## 1. Element-wise（逐点 Map）

每个输出只看同位置输入，线程互不通信。带宽墙。grid-stride + 向量化。

| 题目 | 难度 | 018 |
|---|---|---|
| Vector Addition | Easy | **有** `element_wise/01_vector_add` |
| Matrix Addition | Easy | 换公式，和 vector add 同一核 |
| Color Inversion | Easy | **有** `element_wise/02_color_inversion` |
| RGB to Grayscale | Easy | **有** `element_wise/09_rgb_to_grayscale` |
| Matrix Copy | Easy | **有** `element_wise/05_matrix_copy` |
| ReLU | Easy | **有** `element_wise/03_relu` |
| Leaky ReLU | Easy | **有** `element_wise/04_leaky_relu` |
| Sigmoid | Easy | **有** `element_wise/10_sigmoid`（`σ(x)`） |
| SiLU | Easy | **有** `element_wise/06_silu`（`xσ(x)`） |
| SWiGLU（切半门控） | Easy | **有** `element_wise/07_swiglu` |
| Value clipping | Easy | **有** `element_wise/08_value_clipping` |
| SwiGLU MLP | Medium | GEMM + 07；逐元素半边在 019 `14_swiglu` |

## 2. Permute（下标重排）

不改数值公式，改「谁写到哪」。反转两边都能合并；转置必须 smem。

| 题目 | 难度 | 018 |
|---|---|---|
| Reverse Array | Easy | **有** `permute/01_reverse_array` |
| Matrix Transpose | Easy | **有** `permute/02_matrix_transpose` |
| Interleave arrays | Easy | **有** `permute/03_interleave_arrays` |

## 3. Reduce / Scan

多读一写，或前缀依赖。shuffle + smem 树 + 可选 atomic。

| 题目 | 难度 | 018 / 019 |
|---|---|---|
| Reduction | Medium | **有** `reduce/01_reduction`（`common.cuh`） |
| Dot Product | Medium | **有** `reduce/04_dot_product`（融合乘加，勿先写乘积） |
| Softmax | Medium | **有** `reduce/02_softmax`（online `(m,ℓ)`） |
| Prefix Sum | Medium | **有** `reduce/03_prefix_sum` |
| Histogramming | Medium | 多桶 atomic，新骨架 |
| Top K / Top-p | Medium | 部分排序 + reduce |
| MSE / CCE | Medium | map + reduce |

## 4. GEMM / 乘加

算术强度高，tile + smem。

| 题目 | 难度 | 018 / 019 |
|---|---|---|
| Matrix Multiplication | Easy | **有** `gemm/01_matrix_mul` |
| Sparse MatVec（稠密布局） | Medium | **有** `gemm/02_spmv`（按行 GEMV，非 CSR） |
| **GEMM（α/β，FP16）** | Medium | **有** `gemm/03_gemm` |
| Batched GEMM | Medium | 同一套 tile |
| Sparse / INT8 MatMul | Hard | 019 量化口播 |

## 5. Stencil / 卷积

一个输出吃一段邻域。输入被邻居复用 → smem halo；小 kernel 可放常量内存。

| 题目 | 难度 | 018 |
|---|---|---|
| 1D Convolution | Easy | **有** `stencil/01_conv1d` |
| 2D Convolution | Medium | **有** `stencil/02_conv2d` |
| 3D Convolution | Medium | **有** `stencil/03_conv3d` |
| Gaussian Blur / Max Pool | Medium | 固定 K 的 stencil |
| 2D Jacobi | Medium | 迭代 stencil |
| Causal Depthwise Conv1d | Medium | 加因果边界 |

## 6. Attention / Transformer

行归约 + GEMM tile；FA 再加 online merge。

| 题目 | 难度 | 019 |
|---|---|---|
| Softmax Attention | Medium | **有** `attention/01_naive` · `02_online` · `03_flash_v2`（**不是**必须 FA） |
| Grouped Query Attention | Medium | `09` 头：`kv_head = q_head / g` |
| RoPE | Medium | `13_rope` |
| RMSNorm / BatchNorm | Medium | `03_rmsnorm` |
| Linear / Decaying Causal Attn | Medium | `17_linear_attn` |
| SwiGLU MLP / MoE Top-K | Medium | `14` / `18` `19` |
| Simple Inference | Medium | GEMM + 激活拼盘 |

## 阅读顺序（本目录）

```
elementwise (add → color → ReLU → Leaky → copy → SiLU → SWiGLU → clip → gray → sigmoid)
    → permute (reverse → transpose → interleave)
    → stencil (conv1d → conv2d → conv3d)
    → attention (`01_naive` → `02_online` → `03_flash_v2`；FA 深水在 019)
    → gemm
    → reduce / 按行 softmax / FA（019）
```
