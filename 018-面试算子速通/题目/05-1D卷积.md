# 1D 卷积（Stencil）

**LeetGPU：** Easy · [1D Convolution](https://leetgpu.com/challenges/1d-convolution)  
**目录：** `stencil/01_conv1d`

给定 `input[N]`、`kernel[K]`，**valid** 边界：

$$
\mathrm{out}[i] = \sum_{k=0}^{K-1} \mathrm{input}[i+k]\cdot\mathrm{kernel}[k],\quad 0 \le i < N-K+1
$$

## 接口

```cuda
void solve(const float* input, const float* kernel, float* output,
           int input_size, int kernel_size);
```

device 指针。约束：`N ≤ 1.5e6`，`K ≤ 2047`。计时规模 `N=1.5e6, K=2047`。不许用 cuDNN / cuFFT / CUTLASS。

## 直接写效率高吗

naive（一线程一个 `i`，内层扫 `k`）**对、好写，K 小时够用**。问题是每个输入大约被读 K 次。`K=3` 是带宽墙；`K=2047` 是算力墙，HBM 重复读会被 L2 兜一部分，但面试要讲清复用。

## 能不能套 GEMM

代数上 `out = im2col(in) @ ker`。这题是**单通道**，右边是 `K×1`，所以是 **GEMV 不是 GEMM**。

| 做法 | 这题 |
|---|---|
| 显式 im2col 再 GEMM | 不要。`1.5e6 × 2047 × 4B ≈ 12GB`，带宽先炸 |
| implicit GEMM（CUTLASS / cuDNN） | 生产 2D / 多通道的正解：tile 现场拼，不落 im2col。白板写不完，而且 `N=1` 套不上 Tensor Core |
| FFT 卷积 | `O(N log N)`，大 K 理论更快。题目禁外部库，默写不了 |
| **tile + smem（从 GEMM 偷的）** | **面试停这里。** block 一段输出，输入 halo + 核进 smem，内层 4 展开 |

多通道 `y[c_out, i] = Σ_{c,k} x[c, i+k] w[c_out,c,k]` 才是真 GEMM（`M=nOut, N=Cout, K=Cin·K`）。

## 面试就写这个

一个 block 算 `BLOCK` 个输出，smem 放 `BLOCK+K-1` 个输入；**核进 `__constant__`**（广播，不占 smem）。同步后点积，内层 4 展开。

口播下一档（不必写）：每线程多个输出、`cp.async`。
