# Bias Add / 广播加法

**来源：** 面试扩展练习；形状、接口和边界行为由本题明确约定。

**练习层级：** 基础

给矩阵的每一行加上同一个通道偏置，练习广播索引。

$$
Y_{ij}=X_{ij}+b_j
$$

## 接口

```cuda
void solve(const float* input, const float* bias, float* output, int M, int N);
```

所有指针均指向 **GPU 设备内存**，由调用方分配；标量按值传入。除题面另有说明外，张量按给定形状行优先连续存储，输入和输出不别名。

| 参数 | 含义 |
|---|---|
| `input` | float32 输入，形状 (M, N)。 |
| `bias` | float32 只读偏置，形状 (N,)。 |
| `output` | float32 输出，形状 (M, N)。 |
| `M` | 行数。 |
| `N` | 通道数，即每行列数。 |

## 示例

input=[[1,2],[3,4]]，bias=[10,20]，输出 [[11,22],[13,24]]。

## 约束与对照

M、N 为正整数，输入有限；输入与输出分开分配。

**PyTorch 对照：** `input + bias`
