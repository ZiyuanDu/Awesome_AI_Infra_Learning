# Top-K Selection

从长度为 $N$ 的 32 位浮点数组中选出最大的 $k$ 个值，按 **降序** 写入输出数组。
输入不修改，输出只包含数值；重复值按出现次数保留。

## 接口

```cuda
void solve(const float* input, float* output, int N, int k);
```

所有指针参数均指向 **GPU 设备内存**；数组由调用方分配，尺寸参数和其他标量按值传入。

| 参数 | 含义 |
|---|---|
| `input` | 长度为 N 的只读 float 输入数组。 |
| `output` | 长度为 k 的 float 输出数组，按降序写入最大的 k 个值；不返回下标，重复值保留。 |
| `N` | 输入元素个数。 |
| `k` | 需要返回的最大值个数，要求 1 ≤ k ≤ N。 |

## 示例 1

```text
输入：input = [1, 5, 3, 2, 4], N = 5, k = 3
输出：output = [5, 4, 3]
```

## 示例 2

```text
输入：input = [5, 5, 5, 1, 2], N = 5, k = 3
输出：output = [5, 5, 5]
```

## 约束

- N ≥ 1，1 ≤ k ≤ N。
- k = 1 返回最大值；k = N 时返回整个输入的降序排列。
