# 矩阵乘法（FP32）

**难度：** Easy

给定 32 位浮点矩阵 $A$（$M \times N$）和 $B$（$N \times K$），在 GPU 上计算乘积，结果写入 $C$（$M \times K$）。全部 **行优先**：

$$
C[m, k] = \sum_{n=0}^{N-1} A[m, n] \cdot B[n, k]
$$

下标：$A[mN + n]$，$B[nK + k]$，$C[mK + k]$。

## 接口

```cuda
void solve(const float* A, const float* B, float* C, int M, int N, int K);
```

所有指针参数均指向 **GPU 设备内存**；数组由调用方分配，尺寸参数和其他标量按值传入。

| 参数 | 含义 |
|---|---|
| `A` | 行优先的 M × N 只读 float 矩阵。 |
| `B` | 行优先的 N × K 只读 float 矩阵。 |
| `C` | 行优先的 M × K float 输出矩阵，写入 A × B。 |
| `M` | A 和 C 的行数。 |
| `N` | A 的列数及 B 的行数，即归约维度。 |
| `K` | B 和 C 的列数。 |

- `A`、`B`、`C` 均为 **device 指针**
- 不得修改 `solve` 的签名
- 结果必须写在 `C` 中
- 不允许使用外部库（含 cuBLAS）

## 示例 1

**输入：** $M = N = K = 2$

```
A = [[1, 2],
     [3, 4]]
B = [[5, 6],
     [7, 8]]
```

**输出：**

```
C = [[19, 22],
     [43, 50]]
```

## 示例 2

**输入：** $M = 2,\ N = 3,\ K = 2$

```
A = [[1, 2, 3],
     [4, 5, 6]]
B = [[7,  8],
     [9, 10],
     [11, 12]]
```

**输出：**

```
C = [[58,  64],
     [139, 154]]
```

## 约束

- $1 \le M, N, K \le 8192$
- 计时规模：$M = 8192,\ N = 6144,\ K = 4096$
- 评测卡：NVIDIA 5090Dv2
